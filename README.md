# OmniFall — slide thuyết trình

17 slide (chủ đề vũ trụ) về dự án phát hiện trạng thái ngã trên benchmark OmniFall: dữ liệu và tiền xử lý,
phương pháp Transition-Conditioning, kết quả streaming, báo động và ứng dụng realtime.

Mở `index.html` bằng trình duyệt. Điều khiển: phím ← → / Space, vuốt trên điện thoại, hoặc nút góc dưới.
Toàn bộ biểu đồ và ảnh nằm trong một file duy nhất; chỉ cần mạng để tải font.

Mã nguồn dự án: https://github.com/WuneCutee/omnifall-conditioning

Nhóm: Nguyễn Duy Quân · Phạm Tuấn Vỹ · Nghiêm Thị Thu Huyền · Vũ Hoàng Anh — FPT University.
